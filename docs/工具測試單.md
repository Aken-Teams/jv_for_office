# JVision for Office · 工具測試單

三個宿主、88 題，每題一句測試 prompt。刻意寫得複雜——簡單的輸入幾乎都會過，看不出原因。

> **怎麼用。** 一次複製一句，貼進對應宿主的側邊欄。每題的「要看什麼」不是看它有沒有做出東西，
> 是看它有沒有在那個點上出錯。做出來了但錯在那個點，才是這張單子要抓的。
> 標「（先…）」的題目需要先準備好檔案或選取範圍再送出。


---

## Word（36 個工具）

### 1. `word_get_overview`

**要看什麼：** 空白文件也要講得出東西，不能回「沒有內容」就結束

```
先完整看一次這份文件，告訴我：有幾段、幾張表、每張表幾列幾欄、標題階層長什麼樣，還有哪幾段是空的。不要做任何修改。
```

### 2. `word_insert_cover`

**要看什麼：** 封面五段節奏；承諾不能只是標題換句話說

```
做一份「2027 年度資訊安全稽核報告」的封面。眉標寫「稽核室 · 風險與內控」，承諾那句要講清楚這份報告為了誰、要達成什麼，不要重複標題。文件資訊放：版本 v2.1、提出日期 2027-01-15、稽核期間 2026 全年、負責人（待填）、文件等級 機密。
```

### 3. `word_apply_theme`

**要看什麼：** 七種主題要真的不同；formal/academic 必須回到黑白

```
把這份文件套成公文體（formal），然後告訴我它跟預設的 report 主題差在哪幾項：字型、字級、顏色、行距、首行縮排，一項一項列出來。
```

### 4. `word_insert_toc`

**要看什麼：** 目錄前不能多空白頁、後面不能多一條線

```
幫我在封面後面插目錄，標題用「目次」。插完告訴我目錄是用欄位做的還是純文字做的，以及我需不需要手動按「更新目錄」。
```

### 5. `word_insert_text`

**要看什麼：** 長段落的斷行、全形標點、中英混排

```
在文件最後加三段：第一段講 OWASP Top 10 在本次稽核的適用範圍（要提到 A01、A03、A07），第二段講 ISO 27001:2022 附錄 A 的對應條款，第三段用一句話總結。中英文混排，專有名詞保留原文。
```

### 6. `word_write_range`

**要看什麼：** 只能動指定段落，不能波及鄰居

```
把第 3 段整段改寫成更正式的公文語氣，保留原本所有數字和日期，其他段落一個字都不要動。改完告訴我你動了哪幾段。
```

### 7. `word_read_range`

**要看什麼：** 段落編號要跟畫面對得上

```
讀第 5 到第 12 段，一段一段列出來並標上段號，然後告訴我其中哪幾段其實是表格裡的內容。
```

### 8. `word_delete_range`

**要看什麼：** 刪除要先確認；不能刪錯範圍

```
把第 8 段到第 9 段刪掉，刪之前先把那兩段的內容唸給我聽，確認是我要刪的再動手。
```

### 9. `word_format_range`

**要看什麼：** 樣式階層 vs 直接格式的分際

```
把文件裡所有看起來像章節標題的段落設成 Heading 1，像小節的設成 Heading 2。不要用放大字級的方式做，要真的套樣式——套完我要能用導覽窗格跳章節。
```

### 10. `word_insert_table`

**要看什麼：** 表頭淡底細線、欄寬自動、合計列

```
插一張「稽核發現彙總表」，欄位是：編號、發現事項、風險等級、影響系統、建議改善、負責單位、預計完成日。給我 8 列真實一點的內容，風險等級用高/中/低，最後加一列統計高風險有幾件。
```

### 11. `word_read_table`

**要看什麼：** 要讀得出合併儲存格和空格

```
把文件裡每一張表格都讀一次，告訴我各自是幾列幾欄、第一列是不是表頭、有沒有空白儲存格，以及哪一張表的欄位最多。
```

### 12. `word_fill_table`

**要看什麼：** 只填標籤右邊的空格，不能覆蓋已有內容

```
文件裡那張基本資料表，把「負責單位」填成「資訊安全處」、「複核人」填成「王○○」。已經有內容的格子不要動，填完告訴我你填了哪幾格、跳過哪幾格。
```

### 13. `word_insert_chart`

**要看什麼：** 系列色要跟文件主色同一家，不是藍橘紫

```
插一張長條圖：橫軸是 A01 注入、A03 設定錯誤、A07 認證缺失、A09 記錄不足，縱軸是發現件數 12、7、3、15。標題「依 OWASP 分類的發現件數」，並在圖下加一句圖說。
```

### 14. `word_insert_gantt`

**要看什麼：** 里程碑、進度、今天的線

```
插一張改善時程甘特圖：需求確認 2027-02-01 到 02-14、修補開發 02-10 到 03-20、滲透複測 03-18 到 04-05、結案報告 04-06 到 04-15。今天當作 2027-03-01，標出來。
```

### 15. `word_insert_diagram`

**要看什麼：** 流程圖的文字不能被框線裁掉

```
畫一張弱點處理流程圖：通報 → 初步評估 → 分級（高/中/低三條分支）→ 指派修補 → 複測 → 結案；複測不過要回到指派修補。節點文字用完整的中文句子，不要縮寫。
```

### 16. `word_insert_equation`

**要看什麼：** OMML 要能被 Word 當成真的方程式

```
插入風險值公式：風險 = 威脅發生機率 × 弱點嚴重度 × 資產價值，用真正的數學方程式格式，不要用純文字打。下面再插一個 CVSS 基礎分數的分式。
```

### 17. `word_insert_form`

**要看什麼：** 一張表、不重複；半空列要合併

```
做一份「稽核發現改善回覆單」：分三個區塊——發現資訊（編號、發現事項、風險等級、通報日期）、改善規劃（根本原因、改善措施、預計完成日、負責人）、複核結果（複核人、複核日期、複核意見、是否結案）。改善措施和複核意見要留三行書寫空間。
```

### 18. `word_insert_sidebar`

**要看什麼：** 深色區塊要自己畫底色，字不能被切

```
做一個側欄版面：左邊深色欄放「稽核重點摘要」，列出本次三大風險並用橫條圖標示件數；右邊放說明文字，講這三項為什麼被列為重點。左欄的標題文字會比較長，注意不要被裁掉。
```

### 19. `word_insert_calendar`

**要看什麼：** 月曆是真表格、年曆是圖；沒有內建假日

```
插一個 2027 年 3 月的月曆，在 3/5、3/18、3/26 標上「複測」「結案會議」「報告送出」，其餘日期留白。
```

### 20. `word_insert_block`

**要看什麼：** 引用塊、重點框的樣式要跟主題一致

```
在第 2 段後面插一個重點提示框，內容是「本次稽核未涵蓋委外廠商之系統，該部分將於下一期另案辦理」，樣式要跟文件其他部分協調。
```

### 21. `word_insert_layout`

**要看什麼：** 多欄版面的欄寬與間距

```
做一個三欄並排的版面，三欄分別是「發現」「風險」「建議」，每欄一段文字，欄與欄之間要看得出分隔但不要用粗框線。
```

### 22. `word_page_design`

**要看什麼：** 邊界、紙張方向、浮水印

```
把文件改成 A4 直向、上下邊界 2.5 公分、左右 2 公分，並加上「機密」浮水印。改完告訴我目前的版面設定值。
```

### 23. `word_header_footer`

**要看什麼：** 頁碼要是欄位；頁首要跟著主題變淡

```
頁首放「2027 年度資訊安全稽核報告｜機密」靠右，頁尾放「第 X 頁，共 Y 頁」置中。頁碼要用真正的欄位，不要打死數字。
```

### 24. `word_insert_break`

**要看什麼：** 分頁 vs 分節的差別

```
在第 10 段後面插一個分頁符，然後告訴我分頁符和分節符差在哪裡、什麼情況下我該用分節符。
```

### 25. `word_manage_list`

**要看什麼：** 多階清單的縮排與編號延續

```
把第 15 到第 20 段改成有階層的編號清單：三個主項，每個主項下面兩個子項。編號要連續，子項要縮排。
```

### 26. `word_insert_link`

**要看什麼：** 外部連結與文件內書籤

```
在提到「附件一」的地方加一個跳到該章節的內部連結，並在提到 OWASP 的地方加上官網的外部連結。
```

### 27. `word_search`

**要看什麼：** 要回得出位置，不只是「有」

```
找出文件裡所有出現「風險」兩個字的地方，告訴我在第幾段、前後文是什麼，總共幾處。
```

### 28. `word_replace_all`

**要看什麼：** 全文取代要回報筆數，不能誤傷

```
把全文的「資安」統一改成「資訊安全」，但「資安處」這個單位名稱不要動。改完告訴我改了幾處。
```

### 29. `word_normalize_layout`

**要看什麼：** 只管對齊縮排，不碰字型字級

```
把整份文件的對齊和縮排統一一下，但不要動任何字型和字級。做完告訴我你調整了哪些項目。
```

### 30. `word_review_layout`

**要看什麼：** 編號、換頁門檻、封面檢查、空段落

```
幫我做一次完整的版面檢查，把查到的問題一條一條列出來再修。修完告訴我：哪幾個章節換了頁、為什麼有些章節沒換、編號是怎麼編的。
```

### 31. `word_get_selection`

**要看什麼：** 游標位置、選取範圍要說得準

```
（先在 Word 裡選一段文字）告訴我我現在選的是第幾段、內容是什麼、有幾個字。
```

### 32. `word_read_image`

**要看什麼：** 要看得懂圖裡的內容，不只是說有圖

```
（先貼一張圖表截圖進文件）看一下文件裡那張圖，告訴我它畫的是什麼、有哪些數據、有沒有標示不清楚的地方。
```

### 33. `word_insert_attachment`

**要看什麼：** 附件內容要真的進到文件

```
（先上傳一份 Excel）把附件裡的資料整理成一張表格插進文件，欄位自己判斷，並在表格上方加一句說明資料來源。
```

### 34. `word_read_attachment`

**要看什麼：** 大檔案要分批讀，不能截斷就當讀完

```
（先上傳一份長文件）把附件完整看一次，告訴我它總共幾頁、分幾個章節、每章在講什麼，最後摘要三個重點。
```

### 35. `word_ask_user`

**要看什麼：** 資訊不足時要問，不要自己編

```
幫我寫一份合約，對方公司和金額我還沒決定。
```

### 36. `word_run_script`

**要看什麼：** 高風險操作要先確認

```
用腳本的方式把文件裡所有空白段落一次清掉，執行前先告訴我會刪掉幾段。
```

## Excel（20 個工具）

### 37. `excel_get_overview`

**要看什麼：** 多工作表、已用範圍、公式欄位要分得出來

```
先完整看一次這個活頁簿：有幾張工作表、每張用到哪個範圍、哪幾欄是公式哪幾欄是輸入值、有沒有合併儲存格或隱藏列。不要做任何修改。
```

### 38. `excel_write_range`

**要看什麼：** 一次寫大量資料、型別要正確

```
在 A1 開始建一張銷售明細：欄位是日期、業務、客戶、產品、單價、數量、小計、區域。給我 30 列 2026 年的資料，日期要是真的日期格式不是文字，小計用公式算，區域分北中南。
```

### 39. `excel_read_range`

**要看什麼：** 超過上限要拒絕並指路，不能悄悄截斷

```
把 A1:H1000 整個讀一次，告訴我實際有幾列有資料、每一欄的型別是什麼、有沒有哪一列的欄位數對不上。
```

### 40. `excel_format_range`

**要看什麼：** 數值格式、條件式格式、不能把公式變文字

```
把單價和小計兩欄設成帶千分位的貨幣格式，數量欄設成整數，日期欄設成 yyyy/mm/dd。然後把小計大於 10000 的儲存格標成淺紅底色。
```

### 41. `excel_create_chart`

**要看什麼：** 資料範圍、座標軸、圖例要正確對應

```
依區域做一張各區月營收的折線圖，橫軸是月份、三條線分別是北中南，圖表放在資料右邊不要蓋住資料，標題和座標軸名稱都要有。
```

### 42. `excel_table_ops`

**要看什麼：** 轉成表格物件後排序篩選要還能用

```
把 A1 開始的資料轉成 Excel 表格物件，命名為「銷售明細」，套一個跟資料量相稱的樣式，並讓標題列凍結。
```

### 43. `excel_structure_op`

**要看什麼：** 插入刪除列欄會動到公式參照

```
在第 1 列上面插入兩列當標題區，然後在小計欄右邊插一欄「毛利率」。插完確認原本的公式還指到正確的儲存格。
```

### 44. `excel_manage_sheet`

**要看什麼：** 新增/改名/移動/刪除；刪除要確認

```
新增一張叫「月報表」的工作表放在最前面，把現在這張改名成「原始資料」，然後在月報表裡用公式從原始資料算出每月總額。
```

### 45. `excel_sheet_style`

**要看什麼：** 整張表的視覺一致性

```
把整張工作表的外觀整理一下：標題列加底色、欄寬自動調整、格線淡化、凍結首列首欄。做完告訴我你改了哪些項目。
```

### 46. `excel_data_validation`

**要看什麼：** 下拉清單、範圍限制、錯誤提示

```
幫區域那一欄設下拉選單只能選北區/中區/南區，數量欄限制只能輸入 1 到 999 的整數，輸入錯誤時跳出「數量必須是 1~999」的提示。
```

### 47. `excel_define_name`

**要看什麼：** 具名範圍要能被公式引用

```
把單價欄定義成具名範圍「單價區」，然後在旁邊用這個名稱寫一個平均單價的公式。
```

### 48. `excel_clean_data`

**要看什麼：** 去空白、統一格式、重複值

```
幫我清理這份資料：去掉前後空白、統一全半形、把日期格式不一致的補正、找出完全重複的列。清理前先告訴我發現幾個問題，不要直接改。
```

### 49. `excel_compare_source`

**要看什麼：** 大量比對要分批，不能有筆數天花板

```
（先上傳另一份報表）把這張工作表跟附件的資料逐筆比對，用客戶+產品當比對鍵，列出只在其中一邊的、以及兩邊都有但金額不同的。
```

### 50. `excel_trace_precedents`

**要看什麼：** 追得出公式的來源鏈

```
看一下小計欄的公式是怎麼算出來的，往上追到最源頭的輸入值，把整條鏈列給我。
```

### 51. `excel_cell_comment`

**要看什麼：** 註解要掛在對的儲存格

```
在毛利率那一欄的標題加一個註解，說明計算方式和資料來源。
```

### 52. `excel_search`

**要看什麼：** 要回得出位址，而且跨工作表

```
在整個活頁簿裡找出所有金額超過 50000 的儲存格，告訴我在哪張表的哪個位址、對應的客戶是誰。
```

### 53. `excel_get_selection`

**要看什麼：** 選取範圍、作用儲存格要說得準

```
（先選一個範圍）告訴我我現在選的是哪個範圍、幾列幾欄、裡面有幾個非空值、總和是多少。
```

### 54. `excel_read_attachment`

**要看什麼：** 大檔分批、不能截斷就當讀完

```
（先上傳一份大的 Excel）把附件完整看一次，告訴我有幾張工作表、每張幾列、欄位分別是什麼，然後挑出資料品質最差的那一張並說明原因。
```

### 55. `excel_ask_user`

**要看什麼：** 不足資訊要問，不要自己假設

```
幫我做一張預算表。
```

### 56. `excel_run_script`

**要看什麼：** 高風險操作要先確認再跑

```
用腳本把所有空白列一次刪掉，執行前先告訴我會刪掉哪幾列。
```

## PowerPoint（28 個工具）

### 57. `ppt_get_overview`

**要看什麼：** 空簡報也要講得出狀態

```
先完整看一次這份簡報：幾張投影片、每張有哪些物件、有沒有文字、版面配置是什麼。不要做任何修改。
```

### 58. `ppt_build_slide`

**要看什麼：** 一次把整頁組好，不是堆空白片

```
做一頁「2027 年營運策略」的投影片：標題、副標、三個重點各配一句說明，右邊放一張示意圖的位置。整頁一次做好，不要先放空白再慢慢加。
```

### 59. `ppt_add_slide`

**要看什麼：** 只能做空白片，不該假裝帶得了標題

```
在最後面加三張新的投影片，然後告訴我它們現在各自是什麼版面、裡面有沒有東西。
```

### 60. `ppt_add_text`

## 跨宿主：刻意為難的那幾題（4 題）

### 85. `長程組合`　`Word`

**要看什麼：** 地端模型就是在這裡崩的——會做一半就停下來問

```
幫我做一份完整的「供應商資安評鑑報告」：封面、目錄、頁首頁尾、五個章節（評鑑範圍、評鑑方法、發現彙總表、風險分析圖表、改善建議），發現彙總表至少 10 列，風險分析要有一張圖，最後跑版面檢查。中間不要停下來問我，有不確定的地方自己合理假設並在文件裡標註。
```

### 86. `先讀再改`　`Excel`

**要看什麼：** 不讀就寫是最常見的失敗

```
這張表我改過了，你先看清楚現在長什麼樣再動手：把所有金額欄位統一成兩位小數、把遺漏的區域欄補上、然後在最後加一列合計。不要假設欄位順序跟上次一樣。
```

### 87. `中途改變主意`　`PPT`

**要看什麼：** 能不能收回已經做的，而不是疊上去

```
做五頁產品介紹……等等，改成三頁就好，而且配色換成深色底。前面做的要收掉，不要在上面疊。
```

### 88. `中途按停止`　`三個都要`

**要看什麼：** 停止鍵三段式：伺服器、佇列、確認框

```
幫我做一份 20 頁的完整年度報告，內容越詳細越好。（送出後數到五，按停止鍵）
```
